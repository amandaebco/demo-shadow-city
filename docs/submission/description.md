# Brief description for the submission form (max 1,024 characters)

Shadow City is a city-policy simulator for Jakarta. 1,000–5,000 AI residents, built from official Dukcapil population data, decide how to commute when a policy (central parking tariff +100%, Rp1 transit fare) or event (North Jakarta tidal flood) changes their day. A deterministic engine computes every travel time and cost; Gemini only decides and explains. Planners compare scenarios against a baseline and see who gains and who loses by district and income. Gemini (Vertex AI) generates residents, makes and explains decisions, writes analyst reports and audits the data. Cloud Run hosts the orchestrator, decision service and simulation; Gemma 4 runs on a Cloud Run GPU, distilled from Gemini to 89% agreement. Firestore holds scenarios, ticks, decisions and a cache that replays runs identically for free. Firebase Hosting serves the live map. BigQuery logs every decision with its cost. Clustering cuts model calls by 92%: 5,000 residents simulate in ~2 minutes for under $1.
